# Páginas de Termos e Privacidade para Postiz

Este repositório contém modelos iniciais em português:
- `privacy.html` — Política de Privacidade
- `terms.html` — Termos de Serviço

## Antes de publicar
1. Abra os dois arquivos e substitua todos os campos entre colchetes por informações verdadeiras.
2. Confirme que as descrições correspondem à sua instalação real do Postiz e aos serviços conectados.
3. Não publique os documentos com campos incompletos. Considere obter orientação jurídica se o serviço for oferecido a terceiros.

## Publicar com GitHub Pages
1. Crie um repositório **público** no GitHub.
2. Envie os dois arquivos HTML para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/(root)`, depois clique em **Save**.
6. Aguarde a publicação e teste os dois endereços HTTPS no navegador.

Os endereços devem ficar parecidos com:
- `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/privacy.html`
- `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/terms.html`

Troque os exemplos pelos endereços reais mostrados pelo GitHub Pages. Publicar as páginas não garante a aprovação do aplicativo pelo TikTok.
